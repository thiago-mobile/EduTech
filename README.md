# 📱 EduTech App — Prácticas de Programación Móvil 1 (UNLaM)

Repositorio de práctica desarrollado en el marco de la materia **Programación Móvil 1** de la Universidad Nacional de La Matanza. Este proyecto funciona como un **laboratorio de desarrollo en Android** donde voy aplicando e integrando de manera incremental los diferentes conceptos, herramientas y patrones vistos en la cursada.

## 🎯 Objetivo del proyecto
El propósito no es buscar un producto final comercial, sino experimentar y afianzar conceptos clave del desarrollo móvil nativo en **Kotlin**:
- Uso de componentes de interfaz y layouts avanzados con `ConstraintLayout`.
- Visualización de catálogos dinámicos mediante `RecyclerView` y Adapters personalizados.
- Gestión de navegación, pasaje de datos entre pantallas (`Intents`) y flujos de autenticación.
- Implementación de reglas de negocio complejas (cálculo de comisiones por medios de pago, validación de cupos de alumnos, etc.).
- Práctica con patrones de arquitectura y estructuración de código modular.

## 🛠️ Stack Tecnológico
- **Lenguaje:** Kotlin
- **Plataforma:** Android Nativo (Android Studio)
- **UI:** XML, `ConstraintLayout`, `RecyclerView`
- **Control de Versiones:** Git / GitHub
